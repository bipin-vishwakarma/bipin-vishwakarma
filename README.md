## <img src="https://raw.githubusercontent.com/bipin-vishwakarma/bipin-vishwakarma/main/assets/icon-featured.svg" width="30" /> &nbsp;What I’ve Shipped

- **[`text2handwriting.me`](https://text2handwriting.me/)** · **[`Repo`](https://github.com/bipin-vishwakarma/text2handwriting.me)**  
  TypeScript handwriting studio shipped with payment + refund policy support, hardened auth/checkout flows, Razorpay retry handling, practical guide routes, prerendered SEO routes, real 404s, and refreshed brand assets.
- **[`HyperSolve`](https://github.com/bipin-vishwakarma/HyperSolve)**  
  Python v2.0.0 autonomous assessment engine with zero-API-key multi-brain orchestration, native Windows Dynamic Island-style HUD, multimodal Vision AI solving, native Qt QScreen capture, and auto environment/dependency resolution.
- **[`Solink`](https://solink-omega.vercel.app/)** · **[`Repo`](https://github.com/bipin-vishwakarma/solink)**  
  End-to-end encrypted chat disguised as code with encrypted retry queue, privacy-aware presence + settings sync, custom waveform voice player, and major group/mobile reliability upgrades.
- **[`Friday`](https://github.com/bipin-vishwakarma/Friday)**  
  JARVIS-style multi-agent desktop assistant with voice/vision, FastAPI + WebSockets, local/Gemini/Groq model fallbacks, ADB over Wi-Fi, and shipped QR pairing + QR_DETECTED event flow.
- **[`darwin-watcher`](https://github.com/bipin-vishwakarma/darwin-watcher)**  
  Java Android automation + Telegram remote-control center with keep-alive self-healing accessibility engine, remote gesture dispatch, telemetry/alerts, and one-click wireless/USB ADB provisioning.
